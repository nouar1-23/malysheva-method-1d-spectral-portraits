# Метод Малышевой: одномерные спектральные портреты

Данный репозиторий содержит программу `Mal.m`, предназначенную для построения одномерных спектральных портретов матриц методом Малышевой в среде MATLAB.

## Описание программы
Программа позволяет пользователю задать параметры матрицы и исследовать её спектральные характеристики в заданном диапазоне.

1. Откройте **MATLAB**.
